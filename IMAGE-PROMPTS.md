# DeepGlow – AI photo prompts for the package cards

Generate one image per package. Use ChatGPT (image generation), Google Gemini, Microsoft Designer / Bing Image Creator, Adobe Firefly or Midjourney.
Then save each image with the **exact file name** shown, into:

```
deepglow/assets/img/packages/
```

The website picks each photo up automatically. Until a photo exists, the card shows its current line illustration.

**Size:** landscape 3:2 (for example 1536×1024 or 1200×800). JPG, ideally under 250 KB.
PNG also works: send it to me and I'll convert and compress it.

---

## Tips

- Generate 2–4 versions of each prompt and choose the one where hands, fingers and faces look natural. AI images often get hands wrong.
- Keep the same look across all six: similar lighting, the same white uniform, the same cream tones.
- Don't present these as photos of real DeepGlow clients or of Deepa. They are illustrative images of the services.
- Check the terms of the tool you use to make sure you're allowed to use its images commercially on your website.
